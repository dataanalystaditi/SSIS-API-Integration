📌 About the Project

This project demonstrates how to integrate SSIS (SQL Server Integration Services) with a .NET Core Web API.

  • ETL pipeline in SSIS (dummy configs, no secrets).
  • ASP.NET Core API with Swagger, in-memory DB, GET & POST endpoints.
  • Portfolio-ready showcase with screenshots & setup guide.

⚡ Run Locally

git clone https://github.com/dataanalystaditi/SSIS-API-Integration-Project.git
cd SSIS-API-Integration-Project/API/DummyCustomerApi
dotnet restore
dotnet build
dotnet run --urls "http://localhost:5055"

Swagger UI → http://localhost:5055/swagger
